# Push draft to main, then start a fresh draft

## What happens

1. **Accept "Zoom Responsive Fix"** — the draft created 17 days ago gets merged into the main project, so everything it contains is now part of the site. The draft becomes read-only afterwards.
2. **Create a fresh draft** — a brand-new parallel draft starts from the updated main project, ready for a new direction. You tell me what to explore in it, and it runs in its own chat thread without touching the main site until you accept it.

## Notes

- Accepting a draft does not publish the site — the published version only changes when you publish.
- Nothing in the current main project is overwritten except by the draft's changes (which is the point of accepting it).
