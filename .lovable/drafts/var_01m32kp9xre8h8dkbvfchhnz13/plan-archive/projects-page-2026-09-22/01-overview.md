# Projects page

A new page at `/projects` built from the attached design, using the site's
existing navbar, footer, fonts, colours and scroll-animation feel. Nothing on
the home or About page changes.

## What the page contains

1. **Page title block** — "What we've built together." with the one-line
   intro beneath it, on white, with the thin connector line that steps down
   into the featured block.
2. **Featured project** — Parikrama, Murud House: left panel with the
   "Featured Project" label, location, title, architect, description, the
   three-column spec row (Typology / Architect / Durall's Role), the award
   line and the "Explore Project" link. Right side is a large photo that
   **auto-rotates through the project photos**, with the "01 / 07" counter and
   progress bar advancing with it. Hovering pauses it.
3. **Filter row** — All / Residential / Hospitality / Commercial /
   Institutional / International tabs plus a Sort menu. These **actually
   work**: picking a category filters the grid, Sort reorders it, and cards
   fade/settle into their new positions.
4. **Project grid** — two columns of photo cards (Patina, Sentosa House,
   Chiltron House, Juhu House, Project Bangalore, Banyan Villa) each with its
   number, name, location · architect and a "View Project" link.
5. **Closing band** — the dark "Have a project in mind?" section with the
   "Talk to our team" button, then the existing dark footer.
